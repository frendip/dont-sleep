# Agent Awake — Техническое задание

## 1. Описание проекта

Разработать небольшое нативное приложение для macOS под названием **Agent Awake**.

Приложение должно работать исключительно в **Menu Bar** (верхняя панель macOS), без основного окна и иконки в Dock.

### Главная цель

Позволить MacBook продолжать полноценную работу при закрытой крышке независимо от подключения к зарядке.

Основной сценарий использования:

1. Пользователь запускает AI-агента (Codex, Claude Code и т. д.).
2. Включает Agent Mode через Menu Bar.
3. Закрывает крышку MacBook.
4. MacBook продолжает выполнять процессы и поддерживать сетевые подключения.
5. AI-агент продолжает работу без прерывания.

### Целевое устройство

- MacBook Pro с процессором Apple M4 Pro.
- Актуальная версия macOS.
- Архитектура ARM64 (Apple Silicon).
- Приложение предназначено для личного использования.
- Публикация в App Store не требуется.

---

## 2. Функциональные требования

### Agent Mode: ON

- Предотвращает переход macOS в системный сон.
- Позволяет закрывать крышку MacBook без прекращения работы процессов.
- Работает как от зарядки, так и от аккумулятора.
- Не требует подключения внешнего монитора.
- Обеспечивает непрерывное выполнение фоновых процессов.
- Сохраняет работоспособность Wi-Fi и сетевых подключений.
- Позволяет AI-агентам продолжать выполнение задач.

### Agent Mode: OFF

- Возвращает стандартное поведение macOS.
- При закрытии крышки MacBook снова должен переходить в сон.
- Не оставляет активных ограничений сна, созданных приложением.

### Дополнительный функционал MVP

1. Переключатель Agent Mode ON/OFF.
2. Отображение текущего состояния в Menu Bar.
3. Определение источника питания: Battery / AC.
4. Отображение процента заряда аккумулятора.
5. Автоматическое отключение Agent Mode при заряде ниже 20%.
6. Возможность полностью закрыть приложение.

## 3. Техническая реализация

### Технологический стек

- **Swift** — основной язык.
- **SwiftUI** — пользовательский интерфейс.
- **MenuBarExtra** — интеграция с Menu Bar.
- **IOKit** — информация об аккумуляторе и питании.
- **Foundation / Process** — взаимодействие с системными механизмами.
- **XPC / LaunchDaemon** — при необходимости для привилегированных операций.

Не использовать Electron, Tauri, React или WebView.

Приложение должно быть максимально лёгким и нативным.

### Механизм предотвращения сна

Основной кандидат:

```bash
sudo pmset -a disablesleep 1
```

Для восстановления стандартного поведения:

```bash
sudo pmset -a disablesleep 0
```

Параметр `-a` применяется ко всем профилям питания.

**Важно:** перед реализацией необходимо проверить применимость этого механизма на текущей версии macOS и Apple Silicon.

Необходимо экспериментально подтвердить, что он действительно предотвращает сон при закрытии крышки:

- При подключённой зарядке.
- При работе от аккумулятора.
- Без внешнего монитора.

Не считать механизм гарантированно работающим без тестирования.

Обычный `caffeinate` и `IOPMAssertionCreateWithName(kIOPMAssertionTypeNoIdleSleep)` не являются полноценным решением проблемы закрытия крышки.

Предотвращение idle sleep не равнозначно предотвращению lid sleep.

### Управление привилегиями

Для изменения системных параметров может потребоваться доступ администратора.

Предпочтительная архитектура:

```text
Agent Awake.app
      │
      ├── SwiftUI MenuBarExtra
      │
      ├── PowerMonitor
      │     ├── Battery level
      │     └── Power source
      │
      ├── SleepManager
      │     ├── Enable Agent Mode
      │     ├── Disable Agent Mode
      │     └── Current status
      │
      └── Privileged Helper
            │
            └── pmset / system power management
```

Требования:

- Не запускать всё приложение от root.
- Не хранить пароль администратора.
- Не отключать SIP.
- Не использовать приватные API без необходимости.
- Привилегированный компонент должен выполнять только строго определённые операции.
- Если privileged helper слишком сложен для MVP, предложить более простой вариант с явным подтверждением администратора.

## 5. Безопасность

### Защита аккумулятора

Если Agent Mode включён и MacBook работает от аккумулятора:

- Следить за уровнем заряда.
- При достижении 20% автоматически отключать Agent Mode.
- Восстанавливать нормальные настройки сна.

### Восстановление системных настроек

Необходимо предусмотреть:

- Выключение Agent Mode вручную.
- Завершение приложения.
- Аварийное завершение приложения.
- Перезагрузку macOS.
- Ошибки привилегированного компонента.

**Важно:** `pmset disablesleep` изменяет системную настройку, а не создаёт временное ограничение, привязанное к жизни процесса.

Нельзя полагаться исключительно на обработчик завершения приложения.

Необходимо разработать механизм восстановления настроек после сбоев.

Также нужно сохранять исходное значение параметра и восстанавливать именно его, а не безусловно устанавливать `0`.

### Дополнительные ограничения

- Не допускать незаметного продолжения работы при критически низком заряде.
- Учитывать риск перегрева закрытого MacBook.
- Предупреждать пользователя об опасности использования активного режима при транспортировке ноутбука в сумке или рюкзаке.
- Не изменять другие параметры энергосбережения без необходимости.

## 6. Proof of Concept

Перед разработкой полноценного приложения необходимо проверить основной механизм.

### Тест 1 — работа от зарядки

1. Сохранить текущие настройки энергосбережения.
2. Включить предотвращение сна.
3. Запустить тестовый процесс, записывающий текущее время в файл каждые 5 секунд.
4. Закрыть крышку MacBook на 5 минут.
5. Открыть крышку.
6. Проверить непрерывность записей.
7. Восстановить исходные настройки.

### Тест 2 — работа от аккумулятора

Повторить предыдущий тест без подключённой зарядки.

### Тест 3 — интернет

1. Запустить процесс, выполняющий периодические сетевые запросы.
2. Закрыть крышку.
3. Проверить, что запросы продолжают выполняться.
4. Убедиться, что сеть действительно работала во время закрытия крышки, а не восстановилась только после её открытия.

### Тест 4 — восстановление

1. Отключить Agent Mode.
2. Убедиться, что системные настройки восстановлены.
3. Проверить стандартное поведение MacBook при закрытии крышки.

### Тест 5 — аварийное завершение

Проверить поведение при:

- Принудительном завершении приложения.
- Перезагрузке macOS.
- Ошибке привилегированного компонента.

Убедиться, что MacBook не остаётся бессрочно в режиме отключённого сна.

## 7. Порядок разработки

### Этап 1. Исследование

Изучить доступные механизмы управления сном macOS.

Особое внимание уделить:

- `pmset disablesleep`.
- Ограничениям Apple Silicon.
- Поведению при закрытии крышки.
- Отличиям работы от аккумулятора и зарядки.
- Существующим open-source решениям.

Референс:

https://github.com/gustaferiksson/amped

### Этап 2. Proof of Concept

Создать минимальный тест без графического интерфейса.

Проверить работу с закрытой крышкой.

Не переходить к следующему этапу, пока основной сценарий не подтверждён.

### Этап 3. MVP

Создать SwiftUI-приложение с MenuBarExtra и переключателем Agent Mode.

### Этап 4. Безопасность

Добавить:

- Мониторинг аккумулятора.
- Управление привилегиями.
- Восстановление настроек.
- Обработку аварийных ситуаций.

### Этап 5. Сборка

Собрать приложение в `.app`, которое можно запускать локально без публикации в App Store.

## 8. Критерии готовности

Проект считается успешно реализованным, если:

- [ ] Приложение запускается из Menu Bar.
- [ ] Agent Mode включается одним переключателем после первоначальной настройки.
- [ ] MacBook M4 Pro продолжает выполнять процессы при закрытой крышке.
- [ ] Работа продолжается от аккумулятора.
- [ ] Работа продолжается от зарядки.
- [ ] Внешний монитор не требуется.
- [ ] Сетевые подключения остаются работоспособными.
- [ ] При выключении режима возвращается стандартное поведение macOS.
- [ ] При низком заряде Agent Mode автоматически отключается.
- [ ] Системные настройки не остаются непреднамеренно изменёнными после сбоев.
- [ ] Приложение не требует публикации в App Store.

## 9. Инструкции для Codex

**Начни с исследования и Proof of Concept, а не с написания полноценного приложения.**

Сначала:

1. Определи текущую версию macOS.
2. Проверь доступные механизмы управления системным сном.
3. Изучи применимость `pmset disablesleep` на Apple M4 Pro.
4. Изучи существующие open-source реализации.
5. Предложи минимальный эксперимент для проверки.
6. Получи разрешение пользователя перед изменением системных настроек.

Не выполняй команды с `sudo` без явного разрешения.

После успешного Proof of Concept предложи архитектуру приложения и приступай к реализации.

При выборе технических решений придерживайся принципов:

- Минимальная сложность.
- Нативная реализация.
- Безопасность системных настроек.
- Минимальное потребление ресурсов.
- Простота дальнейшей поддержки.

### Главный приоритет

**Обеспечить реальное продолжение выполнения AI-агентов при закрытой крышке MacBook независимо от источника питания, а не просто предотвращать автоматическое засыпание от бездействия.**

Если выяснится, что выбранный механизм не обеспечивает нужного поведения на текущей версии macOS, не имитируй успешную реализацию. Объясни ограничения и предложи альтернативы.
