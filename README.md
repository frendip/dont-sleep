# Don’t Sleep

Нативное приложение в верхней панели macOS для работы MacBook без системного сна, в том числе с закрытой крышкой. Запускается вручную, без иконки в Dock и автоматического включения режима.

- Семь режимов: без таймера, 5, 15, 30 минут, 1, 4 или 8 часов.
- Повторный выбор таймера запускает полную длительность заново.
- На аккумуляторе режим доступен только при заряде **строго больше 20%**. На зарядке процент не ограничивает включение.
- Выключение и обычный выход ожидают подтверждения восстановления сна.
- Системные службы предназначены для восстановления после аварии интерфейса и перезагрузки; сессия автоматически не возобновляется.

**Статус:** локальная экспериментальная сборка для Apple Silicon. Целевая конфигурация — MacBook Pro M4 Pro, macOS 26.7.1. Выполнены сборка, автоматические проверки, проверка установочного содержимого без установки и просмотр нативных макетов. Предварительные испытания механизма с закрытой крышкой проводились на зарядке и аккумуляторе; они не подтверждают готовность конечного приложения. Службы готовой сборки ещё не устанавливались: выход, закрытая крышка, аварийное восстановление, перезагрузка и энергопотребление требуют аппаратных испытаний. До их завершения версия предназначена для испытаний под наблюдением.

## Сборка и первый запуск

Нужны macOS и инструменты разработки Apple с доступными Swift и macOS SDK. Из каталога проекта:

```sh
./scripts/build-app.sh
```

Результат — `dist/Don’t Sleep.app`. Сборка проверяет целостность и локальную подпись, но **не устанавливает службы и не меняет настройки питания**.

1. Перенесите приложение из `dist` в «Программы» и откройте его вручную.
2. Нажмите значок глаза в верхней панели, затем «Настроить…» и подтвердите системный запрос администратора.
3. Дождитесь подтверждённого состояния «Выключено» и выберите режим.

Службы устанавливаются через `launchd`. Локальная ad-hoc подпись и точные хеши кода привязывают их к этой сборке и пользователю; это не нотарифицированный публичный дистрибутив. После пересборки требуется повторная настройка с правами администратора.

Закрытый работающий MacBook оставляйте на столе или другой открытой поверхности, не в сумке. Блокируйте экран самостоятельно: закрытие крышки при активном режиме не подтверждает блокировку. Расход энергии зависит от выполняемых задач; сохранение интернета, работы стороннего агента и одинаковый со спящим Mac расход не гарантируются.

## Проверки

Из каталога проекта можно выполнить проверки без установки служб и изменения питания:

```sh
swift test
python3 -m unittest discover -s poc/tests
```

[Статус приёмки](docs/implementation/acceptance.md) и [план измерения энергии](docs/implementation/energy-report.md) отделяют автоматические проверки от ещё не выполненных испытаний установленного приложения.
