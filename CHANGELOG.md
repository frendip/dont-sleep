# История изменений

Версия в исходниках может готовиться к выпуску. Опубликованные выпуски отмечаются тегом `vX.Y.Z` и GitHub Release; правила — в [документации разработки](docs/development.md#версии-и-выпуски).

## 0.1.1 — 2026-10-12

### Исправлено

- При открытии меню или окна после простоя больше не появляется краткое ложное предупреждение «Нет данных о питании» с оранжевым значком. Устаревшие данные по-прежнему блокируют включение; подтверждённые проблемы питания и связи отображаются.

### Разработка

- Добавлен выпуск по тегу: проверка версии и тесты, сборка DMG с ad-hoc подписью и создание черновика GitHub Release без автоматической публикации.
- В DMG и описание выпуска включена инструкция первого запуска в macOS без платной подписи Apple.

- Добавлена команда подготовки локального release-коммита и тега: единый номер версии, увеличение номера сборки, обновление журнала и предварительная проверка.
- Обычный CI продолжает тестировать и собирать приложение, но больше не сохраняет архив `.app` в Actions.

- Зафиксированы правила версий продукта, номеров сборок и выпуска; добавлен пункт проверки версии в шаблон PR.
- Кандидат: версия `0.1.1`, сборка `3`. Совместимость IPC не менялась. После обновления подписанного приложения требуется обычная повторная настройка служб.

## 0.1.0 — исходная локальная версия

- Нативные меню и окно управления, семь режимов, защита по заряду и восстановление сна через служебные компоненты.
- Автоматические тесты и CI-сборка для macOS ARM64.

Эта запись описывает исходное состояние проекта; отдельный тег или GitHub Release для `0.1.0` не создавался.
