# Ресурсы оформления DMG

`VolumeIcon.png` — одобренный пользователем эскиз: иконка Don’t Sleep над серебристым диском macOS, прозрачный фон. Создан встроенным ImageGen по исходному `Resources/Assets/AppIcon.png`; сохранён в проекте без изменения одобренного изображения. Не заменяет иконку `.app`.

Задание генерации: объединить чёрную иконку с белым глазом и молнией с компактным серебристым диском внизу, сохранить доминирующий логотип и прозрачные поля, без текста, стрелок и картонной коробки.

Фон, рамка с тенью, тонкие чёрные шевроны и иконка TXT рисуются кодом `scripts/render-dmg.swift`; в фоне нет изображений перетаскиваемых файлов. Размер окна, координаты файлов и флаги Finder задаёт `scripts/dmg_layout.py`. Согласованные координаты главных иконок: (220, 190) и (500, 190), документа: (360, 350); размер окна 720×460.

Сборка создаёт Retina TIFF, ICNS и техническое превью локально. Производственные ресурсы и `.DS_Store` находятся внутри итогового DMG; промежуточные изображения в Git не добавляются. Подробности — `docs/development.md`.
