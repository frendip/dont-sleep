Установка Don’t Sleep и первый запуск

Для Mac с Apple Silicon (M1 и новее). В сборке указан минимум macOS 13;
совместимость со всеми версиями системы не подтверждена. Intel не поддерживается.

Этот выпуск имеет локальную подпись ad-hoc, без Developer ID и нотарификации
Apple. macOS может заблокировать первый запуск. Разрешайте его только для
приложения, которое вы намеренно скачали из репозитория frendip/dont-sleep.

1. Скачайте DontSleep-macos-arm64.dmg из нужного GitHub Release:
   https://github.com/frendip/dont-sleep/releases
2. Если прежняя копия уже работает, выберите «Выключить и выйти» и дождитесь
   завершения. Закрытие окна не завершает приложение.
3. Откройте DMG и перетащите Don’t Sleep.app на ссылку Applications («Программы»).
   При обновлении подтвердите замену прежнего приложения.
4. Извлеките подключённый образ в Finder. Скачанный DMG теперь можно удалить.
5. Откройте Finder → «Программы» → Don’t Sleep. Не запускайте копию внутри DMG.

Если macOS не может проверить разработчика или приложение

После попытки запуска откройте «Системные настройки» → «Конфиденциальность
и безопасность». В разделе «Безопасность» найдите сообщение о Don’t Sleep
и нажмите «Всё равно открыть» (Open Anyway). Подтвердите запуск; при запросе
введите пароль учётной записи Mac. Названия кнопок зависят от версии macOS.
Обычно это разрешение сохраняется для приложения; новая сборка может снова
потребовать подтверждения.

Если нужной кнопки нет, повторите попытку запуска и откройте настройки снова.
На управляемом рабочем Mac разрешение может ограничивать администратор.
Сообщения «приложение повреждено» или «навредит компьютеру» требуют отдельной
проверки: не считайте их обычным предупреждением о неизвестном разработчике.
Не отключайте Gatekeeper или SIP и не удаляйте карантин командами из интернета.
Инструкция Apple: https://support.apple.com/ru-ru/102445

Настройка самого приложения

В окне Don’t Sleep нажмите «Настроить…» и подтвердите системный запрос
администратора для установки служебных компонентов. Дождитесь «Выключено»,
затем выберите срок и включите режим. После обновления сборки повторите
настройку, если приложение её запросит. При запуске из двух мест откроется
уже работающая копия; для смены сборки сначала полностью выйдите из неё.

Работающий закрытый MacBook оставляйте на открытой поверхности, не в сумке.
Для удаления сначала выключите режим и используйте штатное удаление служб:
https://github.com/frendip/dont-sleep/blob/main/docs/troubleshooting.md#удаление
