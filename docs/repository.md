# Что хранить в Git

## Версионируемые файлы

В репозиторий входят `Package.swift`, `.gitignore`, `README.md`, `CHANGELOG.md`, `Sources/`, `Tests/`, `Resources/`, `scripts/`, `.github/` с конфигурацией CI и шаблоном PR, `poc/` с тестами и актуальные документы `docs/*.md`. В `docs/images/` допустимы выбранные проверенные иллюстрации текущего интерфейса.

Ресурсы иконки хранятся вместе с исходниками: сборка напрямую использует ICNS; PNG, SVG и iconset доступны для просмотра и изменения оформления. Исполняемые права shell-скриптов тоже являются частью Git. Если появятся внешние Swift-зависимости, добавьте `Package.resolved`: он не исключён из Git.

## Только локально

- `.build/`, `.swiftpm/`, `DerivedData/`, `xcuserdata/` — сборка и состояние инструментов.
- `dist/` — приложения, прошлые сборки, экспорт иконок и полный набор превью. Готовые бинарники при необходимости распространяются отдельно от исходного дерева.
- `.scratch/` — тестовые логи, временные исследования и диагностические материалы.
- `.local/` — локальный архив и личные рабочие материалы.
- `.cursor/`, `.vscode/`, `.idea/`, `.superpowers/` — локальная конфигурация редакторов и агентов. Общие настройки команды можно добавить позже явным решением.
- `docs/validation/` — прежнее местоположение сырых аппаратных логов; для новых логов предпочтительнее `.scratch/`. В Git хранится только проверенный итог в `docs/validation.md`.
- `.env*` (кроме `.env.example`), закрытые ключи и контейнеры подписи — локально. `.gitignore` не заменяет проверку содержимого перед публикацией.

Системный каталог `/Library/Application Support/DontSleep` — данные установленного приложения; он не относится к исходному проекту и не должен копироваться в репозиторий.

Их актуальные сведения перенесены в руководство пользователя, архитектуру, разработку, статус проверки и протокол измерения энергии. Архив не является действующей документацией; в нём намеренно сохранены исторические формулировки и старые ссылки. Удаление из рабочего дерева не переписывает предыдущие коммиты.

**История Git сохранена по решению владельца.** Прежние черновики, логи и изображения остаются в ранних коммитах и попадут в первый push вместе с историей. Новые правила исключения не удаляют уже закоммиченные данные. Если в истории обнаружатся секреты, уборки рабочего дерева будет недостаточно.

## Проверка перед первым push

```sh
git status --short
git diff --check
git diff --stat
git ls-files --others --exclude-standard
git status --short --ignored
```

Просмотрите изменения и новые файлы: новые исходники и тесты тоже должны попасть в будущий коммит. После добавления выбранных файлов в индекс проверьте итоговый список и содержимое:

```sh
git diff --cached --name-status
git diff --cached --check
git diff --cached
```

Документация и уборка сами не создают коммит и не выполняют push. Лицензия распространения пока не выбрана; не добавляйте произвольную лицензию от имени владельца проекта.
